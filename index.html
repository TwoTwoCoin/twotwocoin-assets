FAQ

Clear answers.

The token exists on-chain; recognition in wallet interfaces and future features depend on external services and project development.

Is TwoTwoCoin verified in Tonkeeper?

The project has submitted a public verification request (#6797). Submission is not approval. Check the linked request for its current status.

Why might a wallet show no TTC price?

DEX quotes and wallet price feeds use different data and eligibility rules. A live pool doesn't guarantee that every wallet displays its token price.

Can more TTC be created?

Yes. The administrator currently has minting rights. Verify current supply on-chain; do not interpret 22 million as a fixed cap.

Does TTC have a guaranteed return or published utility?

No investment return is guaranteed. Specific token utilities and distribution commitments have not been publicly finalized on this page. Only published, verifiable commitments should be relied on.
